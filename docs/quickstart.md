# 快速开始

按顺序做三件事：安装并打开、归档一份最终稿、在窗口里确认。提示词发给正在使用的 Agent，不用自己执行命令。

支持 Claude Code、Cursor、Codex，以及其他能安装 Skill 的 Agent。每个 Agent 安装一次，之后直接归档。

## 安装并打开

把下面这段话按原文发给 Agent。其中的目录名是给 Agent 看的，不用自己去找文件。

```text
请从 https://github.com/atorber/agentshelf 安装 Skill agentshelf-archive（目录 skill/agentshelf-archive）。安装到我当前使用的 Agent 的用户级 skills 目录，使所有项目可用。安装完成后告诉我安装位置，并打开 AgentShelf。如果打不开，说明原因，不要声称已经打开。
```

完成后应同时满足这三件事：

- Agent 回复了 Skill 的安装位置。
- 本机打开了 AgentShelf 窗口。
- 窗口左侧显示服务在响应。

已经安装过、只是窗口没开时，发这一句即可：

```text
请打开本机的 AgentShelf。如果打不开，说明原因，不要声称已经打开。
```

窗口停在「正在启动」时，看 [排查](troubleshooting.md)。

## 归档第一份文件

任务结束、这份成果可以留下之后，对 Agent 说：

```text
把这份最终稿归档到 AgentShelf。
```

不用写路径、名称、项目或标签。Agent 会自己找到当前这份最终稿，并填上名称、项目、标签和来源。名称来自文档标题或文件名，项目来自当前项目，来源是正在使用的 Agent。原文件仍留在项目里。

它会回复产物名称、编号和版本，以及填上的项目和标签。记下编号，以后把新版本追加到同一份产物时用得上。要改这些信息，在窗口详情里保存即可。

有多份最终稿时，它会逐个归档。某一份失败时，其余文件仍会分别告诉你结果。分不清是哪一份时，它会先问你。

## 在窗口里确认

打开产物库，点进刚才那一份，看这三项：

- 能预览正文、表格或图片。暂时不能预览的格式，仍然可以下载。
- 名称、项目、标签和来源已经填好。
- 详情里能看到当前版本。

这三项都对，第一次归档就完成了。以后每次任务结束，重复上一节即可。更多说法见 [在 Agent 中使用](agent.md)。

## 内容已经存在时

Agent 列出库里已有的相同内容时，回复其中一种：

```text
新建一份产物，不要并到已有记录上。
```

```text
追加到产物「周报」，作为新版本。
```

把「周报」换成 Agent 列出的那一份名称或编号。它不会按文件名自行覆盖。

## 自己放入文件

不想经过 Agent 时，打开窗口里的「上传」，点击选择或拖入文件，填写名称、项目和标签后开始上传。内容和上面相同：重复时选择新建一份产物，或追加为已有产物的新版本。页面上的各项说明见 [使用说明](usage.md)。
