# 排查

先看窗口左侧的服务状态，以及设置页里的说明。日志留在本机数据目录中，不会发到外部。

## 停在「正在启动」

窗口会等待本机服务就绪。超时后，页面会提示重新打开。

把下面这段话再发给 Agent：

```text
请重新打开本机的 AgentShelf。如果打不开，告诉我失败原因，不要声称已经打开。
```

## 预览或校验失败

某一份文件预览失败时，产物记录、下载和校验仍然可用。损坏的文件不会让整个窗口退出。

校验结果不一致时，先不要把当前这份当作原件。可以从最近的备份恢复，或重新归档一份你确认过的文件。

## 检索没有结果

- 检索词尽量写完整一些。很短的词会按普通匹配查找。
- 全文检索包含历史版本。筛选项过多时，先清空项目、标签、来源和格式。
- 「语义」和「混合」需要已在设置页导入并启用本地模型。设置页会写明当前原因。
- 索引还在进行时，设置页能看到尚未完成的任务。失败任务会显示原因。

## 备份恢复失败

恢复前确认选中的是 AgentShelf 生成的备份。恢复会先移开现有数据，失败后再移回。如果设置页显示数据不完整，先不要继续写入，再从一份完好的备份恢复。

恢复会替换当前产物库。开始前可以先再做一份当前数据的备份。

## 产品范围

库中保存明确归档的最终成果，以及来源、项目和版本。只接收你或 Agent 提交的文件。

语义检索在设置页启用后可用。未启用时，全文检索、预览和备份保持可用。页面内预览覆盖 Markdown、文本、CSV、JSON、PNG、JPEG、GIF、WebP 和 PDF。其余格式可以归档和下载。
