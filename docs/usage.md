# 使用说明

界面用来浏览和整理已经归档的最终成果。四个页面分别是产物库、上传、整理、设置。左侧显示服务是否在响应，以及当前产物数量。

这里看的是产物本身：预览、版本和来源。Agent 的思考过程和执行日志不在这些页面里。

## 产物库

产物库是首页。搜索框匹配标题、正文和文件名。有检索词时，可以选择检索方式：

| 方式 | 何时使用 |
|---|---|
| 全文 | 默认方式。按字面匹配标题、正文和文件名 |
| 语义 | 已启用本地模型时，按意思相近来找 |
| 混合 | 同时使用全文和语义 |

还可以按项目、标签、来源 Agent 和格式筛选。格式包括 Markdown、文本、CSV、JSON、图片、PDF 和其他。

少于 3 个字符的检索会退回普通匹配。SQLite 支持 trigram 分词时，中文全文检索更合适；设置页会显示当前使用的分词器。

搜索结果包含历史版本。命中旧版本时，条目上会标出版本号。点进结果会打开对应产物，并定位到那个版本。

没有检索词时，页面按产物列出库里的内容。空库会提示去上传，或让 Agent 通过命令行归档。

## 上传

上传页支持点击选择、拖拽和多文件。上传前可以填写：

- 名称。每个文件单独填写，默认是去掉扩展名后的文件名。
- 描述、项目、标签和来源。这一组会应用到本次上传的文件。标签用逗号分隔。

上传过程中可以看到每个文件的进度。结果逐个保留：成功的文件会给出产物链接；失败的文件显示原因；内容重复的文件会要求你选择处理方式。

两种处理方式：

- 创建新产物。内容相同，但是另一份独立产物。
- 追加到已有产物。成为该产物的新版本。

物理文件仍然按内容只保存一份。选择「新产物」不会再复制一份相同字节。

## 产物详情

详情页展示当前选中的版本：格式、原始文件名、大小和 SHA-256。

可以做这些事：

- 预览。Markdown、文本、CSV、JSON、PNG、JPEG、GIF、WebP 和 PDF 直接在页面里看。CSV 预览最多 200 行、40 列。文本类预览有长度上限，超出会截断并标明。SVG 不作为图片内嵌。其余格式提供下载。
- 下载原始文件。保存前会用响应头里的 SHA-256 核对内容，不一致时取消保存。
- 校验。重新计算磁盘上的文件哈希，并与记录比对。
- 修改名称、描述、项目、标签和来源，然后保存。这改的是产物信息，不产生新的文件版本。
- 在版本列表里切换历史版本。把某个历史版本恢复后，它会成为新的当前版本，原有版本仍留在历史里。
- 删除产物。删除前会要求确认。删除后不能从产物库里再找回这份记录。

预览失败只影响这个文件的预览。产物记录还在，可以继续下载和校验。

## 整理

整理页管理三类信息，它们只用于归档和筛选：

| 类型 | 可填写的附加信息 | 删除后 |
|---|---|---|
| 项目 | 描述 | 产物还在，只是不再属于这个项目 |
| 标签 | 无 | 从筛选里去掉这个标签 |
| 来源 Agent | 备注 | 产物还在，只是不再标记这个来源 |

每一项都会显示关联的产物数量。可以新建、改名和删除。

## 设置

设置页分为服务、存储、备份与恢复、语义检索和 Skill 说明。

服务区显示版本、监听地址、全文分词器，以及数据库完整性检查结果。这里也能看到待处理任务和失败任务。索引任务放在本地队列里，异常退出后，未完成的任务会在下次启动时继续。

存储区显示数据目录、产物数、版本数、物理文件数和占用空间，并分开统计对象文件、数据库和备份。可以复制路径。在桌面应用里还可以直接打开这个目录。

备份、语义检索和故障提示的操作细节见 [数据与接口](reference.md) 与 [排查](troubleshooting.md)。
