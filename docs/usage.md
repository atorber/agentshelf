# 使用说明

窗口用来浏览和整理已经归档的最终成果，包含预览、版本和来源。四个页面分别是产物库、上传、整理、设置。左侧显示服务是否在响应，以及当前产物数量。

对 Agent 说「把这份最终稿归档到 AgentShelf。」即可。名称、项目、标签和来源会自动填上，要改时在详情里保存。说法见 [在 Agent 中使用](agent.md)。

## 产物库

产物库是首页。搜索框匹配标题、正文和文件名。有检索词时，可以选择检索方式：

| 方式 | 何时使用 |
|---|---|
| 全文 | 默认方式。按字面匹配标题、正文和文件名 |
| 语义 | 已在设置里启用本地模型时，按意思相近来找 |
| 混合 | 同时使用全文和语义 |

还可以按项目、标签、来源 Agent 和格式筛选。格式包括 Markdown、文本、CSV、JSON、图片、PDF 和其他。

搜索结果包含历史版本。命中旧版本时，条目上会标出版本号。点进结果会打开对应产物，并来到那个版本。

没有检索词时，页面按产物列出库里的内容。还没有产物时，可以去上传，或让 Agent 归档一份最终稿。

## 上传

上传页支持点击选择、拖拽和多文件。一次放入的文件会归档为同一份产物。上传前可以填写名称、描述、项目、标签和来源。只有一个文件时，名称默认是去掉扩展名后的文件名。标签用逗号分隔。

上传过程中可以看到进度。成功后给出产物链接。内容重复时，需要选择处理方式。

两种处理方式：

- 创建新产物。内容相同，但是另一份独立产物。
- 追加到已有产物。成为该产物的新版本。

物理文件仍然按内容只保存一份。选择「新产物」不会再复制一份相同字节。

## 产物详情

详情页展示当前选中的版本。产物只有一个文件且支持预览时，页面直接打开预览。有多个文件时，先显示文件列表，点开其中一项再预览。

可以做这些事：

- 预览。Markdown、文本、CSV、JSON、PNG、JPEG、GIF、WebP 和 PDF 直接在页面里看。CSV 最多显示 200 行、40 列。文本过长会截断并标明。SVG 不作为图片内嵌。其余格式提供下载。单个不支持预览的文件仍显示下载说明，不先进入文件列表。
- 下载原始文件。保存前会核对内容与记录是否一致，不一致时取消保存。
- 校验。重新计算文件内容，并与记录比对。
- 修改名称、描述、项目、标签和来源，然后保存。这改的是产物信息，不产生新的文件版本。
- 在版本列表里切换历史版本。把某个历史版本恢复后，它会成为新的当前版本，原有版本仍留在历史里。
- 删除产物。删除前会要求确认。删除后不能从产物库里再找回这份记录。

预览失败只影响这个文件的预览。产物记录还在，可以继续下载和校验。

## 整理

整理页管理三类信息，它们只用于归档和筛选：

| 类型 | 可填写的附加信息 | 删除后 |
|---|---|---|
| 项目 | 描述 | 产物还在，只是不再属于这个项目 |
| 标签 | 无 | 从筛选里去掉这个标签 |
| 来源 Agent | 备注 | 产物还在，只是不再标记这个来源 |

每一项都会显示关联的产物数量。可以新建、改名和删除。

## 设置

设置页分为服务、存储、备份与恢复、语义检索。

服务区显示版本、本机状态，以及数据库是否完整。这里也能看到尚未完成的索引和失败原因。异常退出后，未完成的索引会在下次打开时继续。

存储区显示数据目录、产物数、版本数、文件数和占用空间。可以复制路径。在桌面窗口里还可以直接打开这个目录。

备份与恢复：

- 创建备份会生成一份包含产物记录和文件的压缩包。
- 恢复会替换当前产物库。开始前会要求确认。失败时会把原来的数据移回。
- 可以从已有备份恢复，也可以选择一份备份文件恢复。

语义检索是可选项。在设置页填入本机上的模型目录，校验通过后再启用。目录里需要有模型配置和权重文件。应用不会替你下载模型。关闭或未启用时，全文检索和预览保持可用。可以重建或删除语义索引，删除索引不会删除产物文件。
