# 使用

窗口用来浏览和整理已经归档的最终成果。四个页面是产物库、上传、整理、设置。左侧显示服务是否在响应、产物数量和版本。

对 Agent 说「把这份最终稿归档到 AgentShelf。」即可。名称、项目、标签和来源会自动填上，要改时在详情里点「编辑」。说法见 [在 Agent 中使用](agent.md)。

## 产物库 { #library }

产物库是首页，一行一条。没有检索词时按产物列出，显示格式或文件数、名称、项目、标签、来源和更新时间。

搜索框匹配标题、正文和文件名。输入检索词之后，旁边才出现检索方式：

| 方式 | 何时使用 |
|---|---|
| 全文 | 默认。按字面匹配标题、正文和文件名 |
| 语义 | 已在设置里启用本地模型时，按意思相近来找 |
| 混合 | 同时使用全文和语义 |

还可以按项目、标签、来源和格式筛选。格式包括 Markdown、文本、CSV、JSON、图片、PDF 和其他。有筛选时，右侧出现「清除筛选」。

筛选和检索词写在地址里。从详情返回、点侧边栏的「产物库」，或刷新页面，都会回到刚才的结果。

搜索结果包含历史版本，并带上命中片段。命中旧版本时，条目上会标出版本号，点进去就来到那一版。

没有匹配时，页面说明是库为空，还是当前筛选没有结果。

## 上传 { #upload }

上传页先是一块拖放区域。选中文件之后，才出现文件列表和信息表单。一次放入的文件归档为同一份产物。

名称、描述、项目、标签和来源都可以留空，稍后在详情里改。只有一个文件且名称留空时，使用去掉扩展名后的文件名。标签用逗号分隔。

上传过程中可以看到进度。成功后给出产物链接，并可以继续上传下一份。内容重复时，需要选择处理方式：

- 创建新产物。内容相同，但是另一份独立产物。
- 追加到已有产物。成为该产物的新版本。

物理文件仍然按内容只保存一份。选择「新产物」不会再复制一份相同字节。

## 产物详情

打开一份产物后，页首是当前位置：产物库、产物名称，以及正在看的文件。标题左边的返回只往上退一级。

产物只有一个文件且支持预览时，页面直接打开预览。有多个文件时，先显示文件列表；点开一项后，预览上方的标签可以切换其他文件。此时返回回到文件列表，再返回才回到产物库。浏览器的后退也按这个顺序走。

打开具体文件后，右上角可以：

- 下载原始文件。保存前核对内容与记录是否一致，不一致时取消保存。
- 校验。重新计算文件内容，并与记录比对。

预览下方显示格式、文件名、大小，以及内容指纹的开头。

右侧「信息」默认只读。点「编辑」后修改名称、描述、项目、标签和来源，再保存或取消。这改的是产物信息，不产生新的文件版本。

「版本」列出每一次归档和恢复。点某一版就查看那一版。把某个历史版本恢复后，它会成为新的当前版本，原有版本仍留在历史里。

删除放在侧栏底部，删除前会要求确认。删除后不能从产物库里再找回这份记录。

预览失败只影响这个文件的预览。产物记录还在，可以继续下载和校验。

能直接看的格式：Markdown、文本、CSV、JSON、PNG、JPEG、GIF、WebP 和 PDF。CSV 最多显示 200 行、40 列。文本过长会截断并标明。SVG 不作为图片内嵌。单个不支持预览的文件直接显示下载说明，不先进入文件列表。

## 整理 { #organize }

整理页分三栏，只用于归档和筛选：

| 类型 | 附加信息 | 删除后 |
|---|---|---|
| 项目 | 描述 | 产物还在，只是不再属于这个项目 |
| 标签 | 无 | 从筛选里去掉这个标签 |
| 来源 Agent | 备注 | 产物还在，只是不再标记这个来源 |

在栏顶输入名称，回车或点「添加」即可新建。描述和备注在建好之后点「编辑」填写。每一项显示关联的产物数量，点数量会打开已经按它筛好的产物库。

## 设置 { #settings }

设置页自上而下是这几块。

**Agent 接入**放着两段可以复制的提示词：一段用来安装 Skill 并打开窗口，一段用来归档。名称、项目、标签和来源由 Agent 填写。内容与已有产物相同时，Agent 会先问你是新建还是追加版本。

**服务**显示版本、监听地址、全文索引，以及数据库是否完整。这里也能看到尚未完成的索引和失败原因。异常退出后，未完成的索引会在下次打开时继续。

**存储**显示数据目录、产物数、版本数、文件数和占用空间。可以复制路径。在桌面窗口里还可以直接打开这个目录。

**备份与恢复：**

- 创建备份会生成一份包含产物记录和文件的压缩包。
- 恢复会替换当前产物库。开始前会要求确认。失败时会把原来的数据移回。
- 可以从已有备份恢复，也可以选择一份备份文件恢复。

**语义检索**是可选项。填入本机上的模型目录，校验通过后再启用。目录里需要有模型配置和权重文件。应用不会替你下载模型。关闭或未启用时，全文检索和预览保持可用。可以重建或删除语义索引，删除索引不会删除产物文件。
