# AgentShelf

AgentShelf 是给个人用的本地产物库。它保存 AI 最终产出的文件，并在这台电脑上完成检索、预览、版本和备份。文件、检索词和使用记录都留在本机。

当前版本是 0.1.0，桌面安装包面向 macOS 与 Windows。

## 它保管什么

一次任务结束后，最终稿常常散落在对话、下载目录和各个项目文件夹里。AgentShelf 把这些文件收进一个本机库。

每份产物有自己的编号。文件名不会拿来覆盖已有产物。文件按 SHA-256 保存，相同内容只留一份物理文件。再次遇到相同内容时，需要明确选择「新建一份产物」或「追加到指定产物」。

思考过程、执行日志和中间文件不进入产物库。拿不准是不是最终稿时，先确认再归档。

## 两条入口，同一套规则

- 在界面里点击选择或拖入文件，上传前可以填写名称、描述、项目和标签。
- 使用 `agentshelf` 命令，或安装 `agentshelf-archive` Skill，让 Agent 在任务结束时归档。

界面、命令行和 Skill 都调用本机的同一套服务。哈希、去重、版本和索引规则保持一致。

## 可以做的事

- 按标题、正文和文件名做全文检索，再用项目、标签、来源和格式筛选。全文检索会包含历史版本。
- 直接预览 Markdown、文本、CSV、JSON、PNG、JPEG、GIF、WebP 和 PDF。其他格式提供下载。
- 下载原始文件，并重新计算 SHA-256 与记录比对。
- 查看版本历史，把某个历史版本恢复成新的当前版本。
- 管理项目、标签和来源 Agent。
- 在本机创建 zip 备份，或从备份恢复。
- 自行导入本地向量模型后，启用语义检索。未启用时，归档、全文检索、预览和备份仍然完整可用。

## 数据留在本机

本地服务只监听 `127.0.0.1`。它不从外部加载界面资源，也不会把产物、检索词或使用记录发到外部服务。语义检索使用你自己导入的模型，应用不会下载模型。

macOS 上的默认数据目录是 `~/Library/Application Support/AgentShelf`。目录位置、占用空间和服务状态可以在设置页查看。

## 当前版本包含的范围

当前版本面向一个人在自己的电脑上使用：打开应用、归档最终稿、检索预览、管理版本，以及做本地备份。

账号体系、云同步、远程访问、团队权限、Agent 执行过程管理和整盘扫描不在这个版本里。
