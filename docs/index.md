# AgentShelf

AgentShelf 是面向多个 AI Agent 的本地最终产物库。Claude Code、Cursor、Codex，以及其他支持 Skill 的 Agent，完成任务后通过同一个归档 Skill 把最终成果交到这台电脑上。你可以在一个界面里检索、预览、保留版本，并在需要时恢复和备份。

文件、检索词和使用记录都留在本机。当前版本是 0.1.0，桌面安装包面向 macOS 与 Windows。推送到 `main` 后，这份文档会发布到 <https://atorber.github.io/agentshelf/>。

## 它解决的问题

一次任务结束后，最终稿常常散落在各个 Agent 的对话、下载目录和项目文件夹里。换一个 Agent 继续改同一份成果时，很难回答三件事：文件在哪、哪一版是现在用的、它从哪个 Agent 来。

AgentShelf 把值得留下的最终成果收进同一个本机库：

- **统一归档。** 各 Agent 安装同一个 Skill，或直接用命令行和界面提交。原项目里的文件仍留在原处，库里保存一份副本。
- **统一检索。** 按标题、正文、文件名查找，再用项目、标签、来源 Agent 和格式筛选。
- **版本可追溯。** 每份产物有稳定编号。后续更新生成新版本，旧内容仍可预览，并可以恢复成新的当前版本。

## 分工

Agent 负责把成果做出来。Skill 负责识别最终稿、补上名称和来源，并调用本机服务。AgentShelf 负责保存文件、计算哈希、建立版本、做索引，并在界面里展示。

每个 Agent 保持原来的工作方式。不需要各自实现一套归档逻辑，也不直接写数据库。产物编号、版本号和存储位置由本机服务决定。Skill 只根据服务实际返回的结果向你报告。

界面手动上传、`agentshelf` 命令和 `agentshelf-archive` Skill 走同一套规则：哈希、去重、版本和索引保持一致。

## 当前版本可以做的事

- 点击、拖拽或一次提交多个文件。上传前填写名称、描述、项目、标签和来源。
- 全文检索标题、正文和文件名，结果包含历史版本。启用本地模型后，可以改用语义或混合检索。
- 直接预览 Markdown、文本、CSV、JSON、PNG、JPEG、GIF、WebP 和 PDF。其他格式提供下载。
- 下载原始文件。保存前用 SHA-256 核对，不一致时取消保存。
- 查看版本历史，把某个历史版本恢复为新的当前版本。
- 管理项目、标签和来源 Agent。
- 在本机创建 zip 备份，或从备份恢复。

相同内容再次归档时，必须明确选择「新建一份产物」或「追加到指定产物」。内容相同只保存一份物理文件；内容相同并不自动当成同一份产物。文件名也不会用来覆盖已有记录。

更完整的产品边界和后续预览、检索方向见 [产品说明](product.md)。

## 数据留在本机

本地服务只监听 `127.0.0.1`。界面资源随应用提供，产物和检索不会发到外部服务。语义检索使用你自己导入的模型，应用不会下载模型。未导入模型时，归档、全文检索、预览和备份仍然可用。

macOS 上的默认数据目录是 `~/Library/Application Support/AgentShelf`。目录位置、占用空间和服务状态可以在设置页查看。
