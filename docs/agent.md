# 在 Agent 中使用

AgentShelf 的安装和归档，都通过你发给 Agent 的提示词完成。Agent 负责安装 Skill、打开本机窗口，并把你点名的最终稿交进去。

思考过程、执行日志和中间文件不要让它归档。拿不准是不是最终稿时，它会先问你。像密钥、令牌或私钥这样的文件，也会先征得你的同意。

## 安装到所有项目

```text
请从 https://github.com/atorber/agentshelf 安装 Skill agentshelf-archive（目录 skill/agentshelf-archive）。安装到我当前使用的 Agent 的用户级 skills 目录，使所有项目可用。安装完成后告诉我安装位置，并打开 AgentShelf。
```

每个 Agent 安装一次。Claude Code、Cursor、Codex 以及其他支持 Skill 的 Agent 使用同一份 Skill。

## 归档

```text
把这份最终稿归档到 AgentShelf。
名称：系统架构设计
项目：agent-platform
标签：架构, 设计
只归档我点名的文件，不要归档过程稿和日志。
```

归档成功后，Agent 会告诉你产物名称、编号和当前版本。这些信息可以以后用来继续追加版本。

多个文件逐个归档。一份失败时，其他文件的结果会分开说明。

## 相同内容

Agent 发现库里已经有相同内容时，会列出候选产物。你回复其中一种：

```text
新建一份产物，不要并到已有记录上。
```

```text
追加到产物「系统架构设计」，作为新版本。
```

## 查找以前的成果

```text
在 AgentShelf 里查找「系统架构」，告诉我产物名称、编号、项目和当前版本。
```

找到之后，可以让它打开对应版本，或把某一份历史版本恢复成新的当前版本：

```text
把「系统架构设计」的上一版恢复为新的当前版本。原来的版本保留。
```

## 它会遵守的规则

- 只提交你确认过的最终成果。
- 按 AgentShelf 实际返回的结果汇报，没有成功时不会说已经归档。
- 不按文件名猜测并覆盖已有产物。
- 不把思考过程、执行日志和中间文件放进库里。
