# 产品说明

AgentShelf 保管各 AI Agent 值得留下的最终成果：文档、代码、图片、报告、数据文件，以及后来对它们的修改。思考过程、工具调用记录和临时中间稿留在 Agent 自己的会话里。

每份产物会记下来源 Agent、所属项目和归档时间。

## 谁来做什么

你负责确认哪些文件值得留下。Agent 负责把这些文件交到 AgentShelf。AgentShelf 负责保存、编号、建立版本，并在窗口里展示。

各 Agent 保持原来的工作方式。安装一次通用 Skill 后，就可以把最终稿交到同一个库。更换 Agent 之后，已经归档的文件和版本仍在。

不想通过 Agent 归档时，直接把文件拖进窗口。两种方式的去重和版本规则相同。

## 归档

对 Agent 说「把这份最终稿归档到 AgentShelf。」即可。它会归档当前这份最终稿，并自行填上名称、项目、标签和来源：名称来自文档标题或文件名，项目来自当前项目，来源是正在使用的 Agent。这些信息可以之后在详情里修改。同一份成果里的多个文件会放进同一份产物。

自己把文件拖进窗口时，在上传页填写名称、描述、项目、标签和来源。名称留空时，使用去掉扩展名后的文件名。

每份产物有自己的编号。两个项目里都叫 `README.md`，也不会因此被当成同一份。内容已经存在时，AgentShelf 列出候选产物，由你选择新建一份，或追加到指定的那一份。它不会按文件名悄悄覆盖。

像密钥、令牌或私钥这样的文件，需要你明确同意后才归档。

相同内容只保留一份文件。选择「新建产物」不会再复制一份相同的字节。

## 产物库与搜索

产物库按最近更新查看已归档的成果，并按项目、标签、来源 Agent 和格式筛选。只有一个可预览文件时，详情页直接打开预览。有多个文件时，先列出文件，再从列表进入预览。

搜索匹配标题、正文和文件名。结果包含历史版本，并带上命中片段。打开后会来到对应的那一版。

语义检索可以在设置里启用。未启用时，全文检索、预览和备份仍然可用。

项目、标签和来源在「整理」里维护。删掉项目或来源，产物还在。

## 版本

每次成功归档或恢复，都会留下一个不再改动的版本。恢复的含义是：按所选历史版本的内容再建一个新版本，并把它设为当前版本。中间的版本还在，版本号继续增加。

删除产物前会要求确认。删除后，这份产物不能再从库里打开。

## 能直接看的格式

| 格式 | 在窗口里 |
|---|---|
| Markdown、文本 | 直接阅读 |
| CSV | 表格，最多 200 行、40 列 |
| JSON | 文本，过长会截断并标明 |
| PNG、JPEG、GIF、WebP | 图片 |
| PDF | 直接预览 |
| SVG | 提供下载 |
| Office 文档、压缩包、数据集等 | 保存并提供下载 |

预览失败只影响这一份文件。文件仍可下载，并核对其内容是否与记录一致。

## 文件放在哪里

产物会复制进本机的数据目录。你项目里的原文件保持不动。具体位置在设置页可以查看和打开。

| 系统 | 默认位置 |
|---|---|
| macOS | `~/Library/Application Support/AgentShelf` |
| Windows | `%LOCALAPPDATA%\AgentShelf` |
| Linux | `~/.local/share/AgentShelf` |

数据留在这台电脑上。AgentShelf 只在本机使用，不扫描整块磁盘，只接收你或 Agent 明确提交的文件。

## 产品范围

AgentShelf 用于归档最终稿、浏览产物库、搜索筛选，以及保留和恢复版本。本地备份，以及你自行启用的语义检索，都包含在内。

它供一个人在自己的电脑上使用。
