# 产品说明

AgentShelf 管理的是各 AI Agent 值得留下的最终成果：文档、代码、图片、报告、数据文件，以及后来对它们的修改。思考过程、工具调用日志、执行轨迹和临时中间文件不进入这个库。

记录「这份文件来自哪个 Agent、属于哪个项目、何时归档」仍然保留。这是产物的来源，不是一次任务的运行监控。

## 谁负责什么

| | Agent | 归档 Skill | AgentShelf |
|---|---|---|---|
| 完成任务、写出最终文件 | 负责 | | |
| 判断哪些文件值得归档 | 按你的确认或 Skill 规则 | 负责建议 | 负责校验并保存 |
| 名称、描述、项目、标签、来源 | 可以提供 | 整理后提交 | 保存，并在界面里可改 |
| 产物编号、版本号、内容哈希、存储位置 | | 只回传服务给出的结果 | 负责决定 |
| 写入数据库和对象文件 | | 不直接写 | 负责 |
| 检索、预览、恢复历史版本 | 可以代为查询 | 调用本机命令 | 负责 |

Skill 是 Agent 和本机库之间的接入层。以后更换 Agent、调整 Skill 的安装方式，或更换界面，已经归档的文件和版本仍然在同一套数据里。

无法调用 Skill 的时候，可以用界面拖入文件，或在终端执行 `agentshelf archive`。两条路的去重和版本规则相同。

## 四个模块

当前版本把日常使用收成这四件事。

### 统一归档

提交时带上文件和元数据。服务先把文件写入临时区，算出 SHA-256，再放进对象库。相同字节只留一份物理文件。

每份产物有独立编号。两个项目里都叫 `README.md`，不会因为文件名相同就被当成同一份。如果内容已经存在，服务列出候选产物，由你选择新建，或追加到指定编号。它不会按文件名静默覆盖，也不会在身份不清时让后一次写入冲掉前一次。

敏感文件，例如看起来含有密钥、令牌或私钥的文件，需要你明确确认后才归档。

### 产物库

产物库按更新查看已归档的成果，并按项目、标签、来源 Agent 和格式筛选。详情页集中展示当前预览、原始文件、哈希、版本列表和来源。

项目、标签和来源在「整理」里维护。删除项目或来源不会删除产物本身。

### 搜索

现在可以按标题、正文和文件名做全文检索。少于 3 个字符时退回普通匹配。结果会带上命中片段；如果命中的是旧版本，打开后定位到那个版本。

语义检索是可选项。你导入本地向量模型并启用后，可以用「语义」或「混合」。文件名、日期和精确用词仍以全文检索为准。未启用模型时，其余功能保持可用。

按字段值查询表格和 JSON、把命中定位到 PDF 页码或代码行，属于后续能力，当前版本还没有。

### 版本

每次成功归档或恢复都会留下不可变的版本。恢复的含义是：按所选历史版本的内容再建一个新版本，并把它设为当前版本。中间版本保留，版本号继续增加。

删除产物前会要求确认。删除后，这份产物不能再从库里打开。

## 怎么看不同格式

打开产物后直接阅读和核对，是这个产品相对于「只给一个下载链接的目录」的区别。当前版本已经能在页面里看这些格式：

| 格式 | 当前版本 |
|---|---|
| Markdown、文本 | 页面内阅读 |
| CSV | 表格预览，最多 200 行、40 列 |
| JSON | 文本预览，过长会截断并标明 |
| PNG、JPEG、GIF、WebP | 图片预览 |
| PDF | 页面内预览 |
| SVG | 不内嵌为图片，可以下载 |
| 其他格式，包括 Office 文档、压缩包和数据集 | 保存、检索元数据，并提供下载 |

解析失败不会让归档失败，也不会让整个应用退出。文件仍可下载，并用 SHA-256 核对。

后续会按使用频率继续做交互：表格排序筛选、代码版本差异、幻灯片逐页查看、图片文字识别，以及在预览里跳到命中位置。复杂、过大或需要单独运行环境的文件，继续以降级预览和原文件下载为准。

## 文件放在哪里

产物会复制进本机受控目录，按内容哈希存放。你项目里的原文件保持不动。

默认数据目录：

| 系统 | 路径 |
|---|---|
| macOS | `~/Library/Application Support/AgentShelf` |
| Windows | `%LOCALAPPDATA%\AgentShelf` |
| Linux | `~/.local/share/AgentShelf` |

服务只监听本机回环地址。它不扫描整块磁盘，只接收你或 Agent 明确提交的文件。

## 这个产品不承担的工作

下面这些不在 AgentShelf 里找开关：

- Agent 的思考过程、工具调用日志和执行轨迹。
- 任务调度、工作流编排和 Agent 运行监控。
- 自动收集所有临时文件和中间稿。
- 账号、云同步、远程访问、局域网共享和团队权限。

当前版本因此聚焦四件事：归档最终稿、浏览产物库、搜索筛选、保留并恢复版本。本地备份和可选的本地语义检索已经一并提供。

接入状态页面、版本差异对照、产物之间的派生关系、审计时间线，以及更多格式的专用交互，会在这四件事稳定之后再加。协议仍然是现在这一套：Skill 和命令调用本机服务，不各自维护一份产物库。
