按顺序做三件事：安装并打开、归档一份最终稿、在窗口里确认。提示词发给正在使用的 Agent，不用自己执行命令。

支持 Claude Code、Cursor、Codex，以及其他能安装 Skill 的 Agent。每个 Agent 安装一次，之后直接归档。

## 安装并打开 {#install}

把提示词按原文发给 Agent。其中的目录名是给 Agent 看的，不用自己去找文件。这段话在窗口的设置页里也可以复制。

<Tabs>
  <TabItem value="install" label="第一次安装" default>
    ```text
    请从 https://github.com/atorber/agentshelf 安装 Skill agentshelf-archive（目录 skill/agentshelf-archive）。安装到我当前使用的 Agent 的用户级 skills 目录，使所有项目可用。安装完成后告诉我安装位置，并打开 AgentShelf。如果打不开，说明原因，不要声称已经打开。
    ```
  </TabItem>
  <TabItem value="open" label="已经安装过">
    ```text
    请打开本机的 AgentShelf。如果打不开，说明原因，不要声称已经打开。
    ```
  </TabItem>
</Tabs>

完成后应同时满足这三件事：

- Agent 回复了 Skill 的安装位置。
- 本机打开了 AgentShelf 窗口。
- 窗口左侧显示服务在运行。

窗口停在「正在连接本地服务」时，看[排查](/troubleshooting)。

## 归档第一份文件

任务结束、这份成果可以留下之后，对 Agent 说：

```text
把这份最终稿归档到 AgentShelf。
```

不用写路径、名称、项目或标签。Agent 会自己找到当前这份最终稿，并填上名称、项目、标签和来源。名称来自文档标题或文件名，项目来自当前项目，来源是正在使用的 Agent。原文件仍留在项目里。

它会回复产物名称、编号和版本，以及填上的项目和标签。记下编号，以后把新版本追加到同一份产物时用得上。要改这些信息，在窗口详情里点「编辑」再保存，不会因此产生新版本。

同一份成果有多个文件时，它们会放进同一份产物。彼此独立的成果才会分开归档。分不清是哪一份时，它会先问你。

## 在窗口里确认

打开产物库，点进刚才那一份，看这三项：

1. 只有一个可预览文件时，打开就能看到正文、表格或图片。有多个文件时，先看到文件列表，点开再预览。暂时不能预览的格式，仍然可以下载。
2. 右侧的项目、标签和来源已经填好。
3. 右侧能看到当前版本。

这三项都对，第一次归档就完成了。以后每次任务结束，重复上一节即可。更多说法见[在 Agent 中使用](/agent)。

## 内容已经存在时

Agent 列出库里已有的相同内容时，回复其中一种：

```text
新建一份产物，不要并到已有记录上。
```

```text
追加到产物「周报」，作为新版本。
```

把「周报」换成 Agent 列出的那一份名称或编号。它不会按文件名自行覆盖。

## 自己放入文件

不想经过 Agent 时，打开窗口里的「上传」，把文件拖进去或点「选择文件」。选中之后再填写名称、项目和标签，然后归档。重复时同样选择新建一份产物，或追加为已有产物的新版本。页面说明见[使用](/usage)。
