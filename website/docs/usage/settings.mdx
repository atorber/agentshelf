设置页自上而下是这几块。数据、索引和备份都留在本机，不会自动下载模型，也不发送遥测。

## Agent 接入

这里放着两段可以复制的提示词：一段用来安装 Skill 并打开窗口，一段用来归档。名称、项目、标签和来源由 Agent 填写。内容与已有知识相同时，Agent 会先问你是新建一条还是追加版本。

## 服务

显示版本、监听地址、全文索引，以及数据库是否完整。这里也能看到尚未完成的索引和失败原因。异常退出后，未完成的索引会在下次打开时继续。

## 存储

显示数据目录、知识条数、版本数、文件数和占用空间。可以复制路径。在桌面窗口里还可以直接打开这个目录。

## 备份与恢复

- 创建备份会生成一份包含知识记录和文件的压缩包。
- 恢复会替换当前知识库。开始前会要求确认。失败时会把原来的数据移回。
- 可以从已有备份恢复，也可以选择一份备份文件恢复。

## 语义检索

语义检索是可选项。填入本机上的模型目录，校验通过后再启用。目录里需要有模型配置和权重文件。应用不会替你下载模型。

关闭或未启用时，全文检索和预览保持可用。可以重建或删除语义索引，删除索引不会删除知识里的文件。
