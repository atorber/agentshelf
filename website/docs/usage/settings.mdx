设置页自上而下是这几块。知识库留在本机。云端备份上传 zip 压缩包。云同步按目录镜像整个存储目录，需要手动执行。不会自动下载模型，也不发送遥测。

## Agent 接入

这里放着两段可以复制的提示词：一段用来安装 Skill 并打开窗口，一段用来归档。名称、项目、标签和来源由 Agent 填写。内容与已有知识相同时，Agent 会先问你是新建一条还是追加版本。

## 服务

显示版本、监听地址、全文索引，以及数据库是否完整。这里也能看到尚未完成的索引和失败原因。异常退出后，未完成的索引会在下次打开时继续。

## 存储

显示数据目录、知识条数、版本数、文件数和占用空间。可以复制路径。在桌面窗口里还可以直接打开这个目录。

## 备份与恢复

- 创建备份会生成一份包含知识记录和文件的压缩包。
- 恢复会替换当前知识库。开始前会要求确认。失败时会把原来的数据移回。
- 可以从已有备份恢复，也可以选择一份备份文件恢复。

## 云端备份

填写标准 S3 的访问地址、区域、Bucket、目录、Access Key 和 Secret Key。访问地址留空时使用 AWS。MinIO 和多数自建服务需要勾选路径风格。

目录是对象前缀，例如 `backups/agentshelf`。备份包会放到这个目录下面。「备份到云端」会先在本机生成一份备份，再上传。Secret Key 只保存在本机数据目录，保存之后页面不再显示。

云端列表里的「恢复」会下载那份备份并替换当前知识库，开始前会要求确认。

## 云同步

云同步和云端备份分开。备份上传的是 zip 压缩包。同步要另设一个 Bucket，并指定一个目录作为根目录，然后按本机数据目录的结构镜像整个存储，包括 `library.db`、对象文件、本地备份和模型。

访问地址、区域和密钥沿用云端备份里已保存的连接。「同步到云端」会上传有变化的文件，并删除该目录里本地已经没有的文件。「从云端拉取」会用云端目录替换本地数据库、文件、备份和模型。开始前都会要求确认。

令牌、S3 密钥、运行状态、日志和暂存不会上传，拉取时也不会覆盖它们。同步目录不能留空，避免误覆盖整个 Bucket。

## 语义检索

语义检索是可选项。填入本机上的模型目录，校验通过后再启用。目录里需要有模型配置和权重文件。应用不会替你下载模型。

关闭或未启用时，全文检索和预览保持可用。可以重建或删除语义索引，删除索引不会删除知识里的文件。
