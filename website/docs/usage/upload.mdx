上传页先是一块拖放区域。选中文件之后，才出现文件列表和信息表单。一次放入的文件归档为同一份产物。

名称、描述、项目、标签和来源都可以留空，稍后在详情里改。只有一个文件且名称留空时，使用去掉扩展名后的文件名。标签用逗号分隔。

上传过程中可以看到进度。成功后给出产物链接，并可以继续上传下一份。

## 内容重复时

<Tabs>
  <TabItem value="new" label="创建新产物" default>
    内容相同，但是另一份独立产物。物理文件仍然按内容只保存一份，不会再复制一份相同字节。
  </TabItem>
  <TabItem value="version" label="追加为新版本">
    成为所选产物的新版本。原来的版本留在历史里，版本号继续增加。
  </TabItem>
</Tabs>

页面上的选择和 Agent 遇到相同内容时的规则相同：不会按文件名覆盖已有记录。
