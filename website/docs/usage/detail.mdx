打开一份产物后，页首是当前位置：产物库、产物名称，以及正在看的文件。标题左边的返回只往上退一级。

## 一个文件和多个文件

| | 打开后 | 返回 |
|---|---|---|
| 一个可预览文件 | 直接打开预览 | 回到产物库，并保留离开前的筛选 |
| 多个文件 | 先显示文件列表。点开后，预览上方的标签可以切换其他文件 | 先回到文件列表，再回到产物库。浏览器的后退也按这个顺序 |
| 一个不能预览的文件 | 直接显示下载说明，不先进入文件列表 | 回到产物库 |

打开具体文件后，右上角可以下载原始文件，或重新校验。下载前会核对内容与记录是否一致，不一致时取消保存。预览下方显示格式、文件名、大小，以及内容指纹的开头。

能直接看的格式：Markdown、文本、CSV、JSON、PNG、JPEG、GIF、WebP 和 PDF。CSV 最多显示 200 行、40 列。文本过长会截断并标明。SVG 不作为图片内嵌。

预览失败只影响这个文件的预览。产物记录还在，可以继续下载和校验。

## 信息

右侧「信息」默认只读，展示项目、标签、来源、文件数和更新时间。

点「编辑」后修改名称、描述、项目、标签和来源，再保存或取消。这改的是产物信息，不产生新的文件版本。

## 版本

「版本」列出每一次归档和恢复。点某一版就查看那一版。

把某个历史版本恢复后，它会成为新的当前版本，原有版本仍留在历史里。恢复不会改写旧版本。

删除放在侧栏底部，删除前会要求确认。删除后不能从产物库里再找回这份记录。
