打开一份产物后，中间是文档预览。有 Markdown 时，它就是正文。标题左边的返回只往上退一级。

## 正文和附件

正文里出现附件文件名时，图片和视频会嵌在该段落后面，其他附件会放成链接。也可以自己写成 `![界面](界面.png)` 或 `[说明](说明.md)`。没有放进这份产物的图片不会从网络加载。

其余图片、视频、PDF 和其他文件列在右侧「附件」。点一项，中间改为预览该文件；「返回正文」回到文档。再返回才回到产物库，并保留离开前的筛选。只有正文、没有附件时，返回直接回到产物库。

右上角可以下载当前正在看的文件，或重新校验。下载前会核对内容与记录是否一致，不一致时取消保存。预览下方显示格式、文件名、大小，以及内容指纹的开头。

能直接看的格式：Markdown、文本、CSV、JSON、PNG、JPEG、GIF、WebP、MP4、WebM、MOV 和 PDF。CSV 最多显示 200 行、40 列。文本过长会截断并标明。SVG 不作为图片内嵌。

预览失败只影响这个文件的预览。产物记录还在，可以继续下载和校验。

## 信息

右侧「信息」默认只读，展示项目、标签、来源、文件数和更新时间。

点「编辑」后修改名称、描述、项目、标签和来源，再保存或取消。这改的是产物信息，不产生新的文件版本。

## 版本

「版本」列出每一次归档和恢复。点某一版就查看那一版。

把某个历史版本恢复后，它会成为新的当前版本，原有版本仍留在历史里。恢复不会改写旧版本。

删除放在侧栏底部，删除前会要求确认。删除后不能从产物库里再找回这份记录。
