学习页用来理解一个 Skill 怎么写、会经过哪些步骤、依赖哪些工具。分析是静态的：只读取文件，不执行脚本，也不改原始文件。

## 从哪里选择

页面会查找本机这些目录里的 `SKILL.md`：

- `~/.cursor/skills`
- `~/.claude/skills`
- `~/.agents/skills`
- `~/.codex/skills`

每一项会标出来源，以及是否可读取。还没有分析过的显示「未分析」。已有报告时可以打开报告。Skill 文件变了会显示「文件已变化」。目录不在上面这些位置时，把 `SKILL.md` 或它所在的目录填进导入路径。

## 两种分析

快速分析只读取 `SKILL.md`。单文件里没有写出的脚本行为、隐藏配置和运行时依赖，不会被写成已知事实。

深度分析读取该目录里的文本文件，包括脚本、参考资料和配置。符号链接不会被跟着读到目录外。`.git`、`node_modules` 和其他依赖目录不纳入。一次最多 80 个文件。单个文本超过 512 KB 时只记录文件，不读取正文。二进制文件不提取正文。

## 工作台

分析完成后，右侧使用同一次结果：

| 页 | 内容 |
|---|---|
| 概览 | 用途、限制，以及这次发现的缺失引用或风险 |
| 流程图 | 按指令中的步骤排列。点一个节点，看说明和出处 |
| 工具 | 命令、地址、脚本和 MCP 名称，以及它们出现的位置 |
| 文件 | 这次纳入的文件。点开后看快照里的文本 |
| 学习报告 | 按「是什么、文件、流程、工具、原理、输入输出、风险、总结」组织 |
| 问答 | 针对当前报告提问 |

可以只看已确认内容，隐藏纯推断节点。流程图和报告不会各写一套结论。

## 证据

每条结论带一种证据：

- 原文：能回到文件和行号。
- 已声明：写在 Skill 前置信息里。
- 文本引用：指令或脚本里出现了调用。
- 推断：根据结构做出的解释，不是已经确认的运行行为。

找不到行号时只给出文件级引用，不会编造行号。静态分析不知道 Agent 运行时实际选择了哪条分支，也不知道动态拼出来的工具调用。

## 报告会留下什么

每次分析生成一份不再改动的快照。同一内容再次分析时打开已有报告。文件变化后生成新快照，旧报告仍可打开。

疑似密钥会在报告正文里换成「已脱敏」。原始 Skill 文件保持原样。要求忽略既有规则的文本只当作不可信内容，不会改变分析规则。

删除学习记录只去掉本机保存的报告，不删除 Skill 目录里的文件。

## 提问

问答只检索当前这份报告，不会把其他 Skill 的内容混进来。回答会区分原文和推断。报告里没有对应内容时，会说明未知，而不是按文件名编造流程。
