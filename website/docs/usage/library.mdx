知识库是首页，按项目分组列出，没有项目的放在最后的「未分组」。每行显示名称、标签、类型、来源、更新时间和大小。点分组标题可以收起这一组。一条知识有多个文件时，文件列在它下面，可以展开或收起。

点名称、更新时间或大小可以排序，再点一次反转顺序。侧边栏「项目」列出所有项目和各自的条数，点一个就只看这个项目。

## 预览和批量操作

点一行，右侧滑出预览，列表留在背后。点下面的某个文件，就预览这个文件，左上角的返回回到正文。预览顶部可以校验、下载，或打开完整详情。按 Esc 或点列表区域关闭。

鼠标移到一行上，左侧出现勾选框，右侧出现下载和打开详情。勾选后，顶部换成批量栏，可以一起删除；删除前会要求确认。

## 搜索

搜索框匹配标题、正文和文件名。输入检索词之后，旁边才出现检索方式：

| 方式 | 何时使用 |
|---|---|
| 全文 | 默认。按字面匹配标题、正文和文件名 |
| 语义 | 已在设置里启用本地模型时，按意思相近来找 |
| 混合 | 同时使用全文和语义 |

搜索结果包含历史版本，并带上命中片段。命中旧版本时，条目上会标出版本号，点进去就来到那一版。

## 筛选

还可以按项目、标签、来源和格式筛选。格式包括 Markdown、HTML、文本、CSV、JSON、图片、视频、PDF 和其他。有筛选时，右侧出现「清除筛选」。

:::info 筛选写在地址里
从详情返回、点侧边栏的「知识库」，或刷新页面，都会回到刚才的结果。地址里还能看到项目、标签、来源和格式。
:::

没有匹配时，页面会说明是库为空，还是当前筛选没有结果。库为空时，可以去上传，或让 Agent 归档一份最终稿。
