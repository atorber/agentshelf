窗口用来浏览和整理已经归档的最终成果。四个页面是知识库、上传、整理、设置。左侧显示服务是否在响应、知识条数和版本。

对 Agent 说「把这份最终稿归档到 AgentShelf。」即可。名称、项目、标签和来源会自动填上，要改时在详情里点「编辑」。说法见[在 Agent 中使用](/agent)。

| 页面 | 用来 |
|---|---|
| [知识库](/usage/library) | 浏览、搜索和筛选。一行一条，点进去看详情 |
| [上传](/usage/upload) | 不经过 Agent，自己把文件放进库 |
| [详情](/usage/detail) | 预览、切换文件、编辑信息和恢复版本 |
| [整理](/usage/organize) | 维护项目、标签和来源。删除它们不会删除已收入的知识 |
| [设置](/usage/settings) | 复制提示词、查看数据目录、备份，以及按需启用语义检索 |
